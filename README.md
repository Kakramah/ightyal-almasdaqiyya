# اغتيال المصداقية

مقال عربي بصيغة موقع تفاعلي عن الوعي الإعلامي وصناعة الترند والمعلومة.

**الموقع:** https://kakramah.github.io/ightyal-almasdaqiyya/

## بنية المشروع

- `index.html`: المقال وبنية الصفحة وبيانات المشاركة.
- `style.css`: التصميم والاستجابة.
- `script.js`: التفاعلات.
- `images/` و`fonts/`: أصول الصفحة.

## المعاينة والتعديل

من جذر المستودع:

```sh
python3 -m http.server 8000
```

افتح `http://localhost:8000/`. راجع قراءة المقال، وتسلسل الأقسام، والروابط والصور على الهاتف والحاسوب قبل الدمج. لا توجد خطوة بناء في جذر المستودع.
